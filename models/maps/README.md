# Preserved open arena / Aufgehobene offene Arena

`Neon-Causeway-open-battle-layout.hovermap.json` is the byte-identical open layout from 0.5.2, preserved as a basis for a future battle mode. It remains importable as a single-player map; no battle rules are implemented. Assets/provenance: [English](../../NEW-ASSETS.en.md), [Deutsch](../../NEW-ASSETS.md).

Die Datei enthält die byteidentische offene Karte aus 0.5.2 als Grundlage für einen späteren Battle-Modus. Sie bleibt im Einzelspieler importierbar; Battle-Spielregeln sind noch nicht implementiert.
